// 01 — APRESENTAÇÃO

A camada de abstração para inteligência sonora.

Librosa é uma biblioteca Python de código aberto voltada para a análise e processamento de áudio e música. Ela oferece uma API simples que simplifica tarefas como carregar arquivos de áudio, extrair características sonoras e visualizar dados, sendo amplamente adotada em projetos de recuperação de informação musical (MIR), reconhecimento de fala e Machine Learning.

// 02 — FUNÇÕES PRINCIPAIS

Três funções. Infinitas possibilidades.

librosa.load()

Converte arquivo de áudio em y (array NumPy) + sr (taxa de amostragem). Primeiro passo de qualquer pipeline Librosa. Padrão: mono, 22050 Hz. Formatos: WAV, MP3, FLAC, OGG.

Uso: pré-processamento, leitura de datasets, preparação para extração de features.

# Carrega arquivo
import librosa
y, sr = librosa.load('musica.mp3')

# Obtém duração
dur = librosa.get_duration(y=y, sr=sr)
print(f"Duração: {dur:.1f}s")

librosa.feature.mfcc()

Extrai Mel-Frequency Cepstral Coefficients — representação compacta de timbre usando escala Mel não-linear (imitando a audição humana). Retorna matriz tempo×coeficientes. Feature mais usada em ML de áudio.

Uso: classificação de gênero, reconhecimento de fala, detecção de emoções em voz.

librosa.beat.beat_track()

Detecta tempo em BPM e posições exatas dos frames de batida. Usa separação harmônica-percussiva internamente.

Uso: sincronização de batidas, DJs, jogos rítmicos, análise musical.
